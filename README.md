# Магазин игрушек Настюши

Магазин построен на полной структуре сайта **6months**: сохранены десктопная и отдельная мобильная версии, автоматический роутер, каталог, страница товара, корзинка, информационная страница, общий футер и GitHub-админка.

## Что изменено

- чёрная стилистика 6months заменена на розовую, кремовую и лавандовую;
- добавлены летающие пиксельные сердечки, котики, лапки и звёздочки;
- добавлены сцены с обнимающимися котиками и мишками за руки;
- одежда, размеры и тексты бренда заменены на игрушки, варианты и истории персонажей;
- админка привязана к `arcyuke/-`;
- через админку можно создавать и удалять товары, менять цены, описания, варианты и остатки, скрывать товары, загружать несколько фотографий и выбирать главную.

## Страницы

- `index.html` — полная главная;
- `mobilebasic/index.html` — отдельная мобильная главная;
- `product_months.html` и `mobilebasic/product.html` — товар;
- `bag.html` и `mobilebasic/bag.html` — корзинка;
- `about.html` и `mobilebasic/about.html` — о магазине;
- `admin.html` — управление каталогом.

## Перед запуском

1. В `assets/js/common.js`, `assets/js/bag.js` и `assets/js/product_months.js` замените `SKIANORAK`, если заказы должен получать другой Telegram.
2. В GitHub Pages выберите публикацию из ветки `main`, каталог `/ (root)`.
3. Для админки создайте fine-grained GitHub token только для `arcyuke/-` с разрешением **Contents: Read and write**.

Token хранится только в `sessionStorage` вкладки браузера.
