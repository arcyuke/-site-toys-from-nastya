# Магазин игрушек Настюши

Розовый адаптивный магазин игрушек на чистых HTML, CSS и JavaScript. Подходит для GitHub Pages и не требует сборки.

## Что уже работает

- каталог с категориями и карточками товаров;
- отдельная страница игрушки и галерея фотографий;
- корзинка с изменением количества и оформлением заказа в Telegram;
- адаптивный дизайн для телефона и компьютера;
- пиксельные сердечки, котики и мишки с лёгкими анимациями;
- админка `admin.html`, которая добавляет, редактирует и удаляет товары, управляет остатками и загружает фотографии прямо в GitHub.

## Настройка

1. В `assets/js/common.js` замените `SHOP_TELEGRAM`, если заказы должен получать другой Telegram-аккаунт.
2. В GitHub откройте Settings → Pages и выберите публикацию из ветки `main`, папка `/ (root)`.
3. Для входа в админку создайте fine-grained GitHub token только для этого репозитория с разрешением Contents: Read and write.

Token хранится в `sessionStorage` браузера и удаляется при выходе или закрытии вкладки.
