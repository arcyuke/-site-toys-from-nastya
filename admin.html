Вход для владельца

Введите GitHub token с доступом Contents: Read and write к репозиторию arcyuke/-site-toys-from-nastya. Token хранится только до закрытия вкладки.

Как создать token
  1. GitHub → Settings → Developer settings.
  2. Fine-grained tokens → Generate new token.
  3. Выберите репозиторий arcyuke/-site-toys-from-nastya.
  4. Repository permissions → Contents → Read and write.

Товары и фотографии сохраняются прямо в магазин.
